# Compas

Strona-wizytówka (Vite + React).

## Uruchomienie lokalne

```bash
npm install
npm run dev
```

Strona będzie dostępna pod adresem [http://localhost:5173/](http://localhost:5173/).

## Publikacja

Push na gałąź `main` automatycznie publikuje stronę przez GitHub Actions (`.github/workflows/deploy-pages.yml`) na GitHub Pages. Strona działa pod domeną [https://danielsyrek.pl](https://danielsyrek.pl).
